# September 13 website artwork

Four course covers were generated using the built-in image generation tool, then exported as 640px JPEGs for the website. Original generated PNGs are retained in the Codex generated_images directory.

Shared prompt: Square full-bleed course illustration, adult editorial comic style, confident loose ink contours, broad flat color, handmade characters, cream/ochre/navy/teal/terracotta palette, one clear focal point, simplified backgrounds, no lettering, logo, border or mockup.

- course-startup.jpg — Evaluating a Startup Idea: founder testing an early product concept with a prospective customer across a table, rough prototype between them.
- course-venture.jpg — Venture Capital: founder explaining a business to two investors in a relaxed meeting room, simple chart on paper.
- course-marketing.jpg — Educational Marketing: educator presenting a useful idea to a small audience, clear diagram on a board.
- course-rome.jpg — The Roman Empire: Roman forum street, classical arch, columns, small citizens in togas, Mediterranean daylight.

Lora_700Bold.ttf is copied from the app's existing Lora font assets. The three-point direction diagram is inline SVG in index.html.
